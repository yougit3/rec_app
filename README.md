# 通話録音アプリ (rec_app)

Android 向けの通話録音アプリです。通話の開始と終了を検知して自動で録音し、相手の番号・名前・発着信の種別とあわせて一覧に保存します。録音は端末内にのみ保存され、外部には送信されません。

> **注意**: 通話を録音する際は、事前に相手へ録音することを伝えてください。録音データの扱いは関係する法令に従ってください。

## 仕組みと制限

Android 10 以降は、通常のアプリが通話音声を直接録音できません。このアプリは、有効化されたアクセシビリティサービスが通話中でもマイク入力を取得できることを利用しています。

- 自分の声は確実に録音されます。
- 相手の声は、端末によって小さい、または録音されないことがあります。スピーカーホンにすると確実に録音できます。
- 音源は設定から切り替えられます（音声認識 / マイク / 通話用マイク）。選んだ音源で開始できないときは、ほかの音源に順に切り替えます。

## 機能

- 通話中の自動録音（設定でオフにできます）
- 通話履歴から相手の番号と発着信種別を取得し、連絡先から名前を補完
- 録音の一覧表示、再生、共有、削除
- 2 秒未満の録音を保存しない設定
- 録音中の通知表示

## 必要な権限

| 権限 | 用途 | 区分 |
| --- | --- | --- |
| `RECORD_AUDIO` | 録音 | 必須 |
| `READ_PHONE_STATE` | 通話の開始・終了の検知 | 必須 |
| `READ_CALL_LOG` | 相手の番号・発着信種別の取得 | 任意 |
| `READ_CONTACTS` | 相手の名前の取得 | 任意 |
| `POST_NOTIFICATIONS` | 録音中の通知（Android 13 以降） | 任意 |
| アクセシビリティサービス | 通話中のマイク入力の取得 | 必須 |

初回起動時の「初期設定」画面で順に設定できます。アクセシビリティは、設定 → ユーザー補助 →「通話録音サービス」をオンにしてください。

## 動作環境

- Android 10 (API 29) 以降
- ビルド: JDK 17、Android SDK Platform 35

## ビルド

```
./gradlew :app:assembleDebug        # debug APK
./gradlew :app:testDebugUnitTest    # ユニットテスト
```

APK は `app/build/outputs/apk/debug/` に出力されます。

## 実機へのデプロイ

`deploy.sh` は、ビルドしたあとにワイヤレスデバッグ経由で APK をインストールします。

1. 端末で「開発者向けオプション → ワイヤレスデバッグ」をオンにし、この PC とペア設定します。
2. `.env.example` を `.env` にコピーし、`PHONE_IP` に端末の IP アドレスを設定します。`.env` は git 管理外です。
3. 実行します。

```
./deploy.sh            # debug 版
./deploy.sh release    # release 版（署名設定が必要）
```

ワイヤレスデバッグのポートは毎回変わるため、`avahi-browse` で mDNS から検出します。`adb` と `avahi-browse`（avahi-utils）が必要です。

## 構成

```
app/src/main/java/com/example/recapp/
├── service/    アクセシビリティサービスと通話状態の監視
├── recorder/   MediaRecorder による録音
├── data/       Room（録音情報）、DataStore（設定）、通話履歴の取得
└── ui/         Jetpack Compose の画面（一覧・設定・初期設定）
```
